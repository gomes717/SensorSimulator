# Results tables

Generated by `scripts/results_tables.py` for the thesis results chapter (issue 15).

## `results_models.md` / `.csv`

Clinical range metrics (TIR/TBR/TAR as time, mean, SD, CV) for each of the four
physiological models over a **fixed standard 24 h day** — the 4-meal schedule in
`STANDARD_MEALS` (breakfast 45 g / lunch 70 g / snack 20 g / dinner 60 g), no
insulin bolus (the simulator models basal only). Run noiseless via the app's
`ModelStepper`, so these rows are **deterministic** — re-running gives identical
numbers. Regenerate:

```
uv run python scripts/results_tables.py --out docs/results
```

The high TAR figures are expected: ~195 g/day of uncovered carbohydrate on
basal-only insulin. Adjust `STANDARD_MEALS` in the script if the chapter wants a
covered-meal or lighter schedule.

## `results_model_x_noise.md` / `.csv` (board — not yet run)

Per **model × sensor-noise model** (Ideal / Breton / Facchinetti), plus **MARD**
of the noisy board stream vs the noiseless model reference. Requires the board:

```
uv run python scripts/results_tables.py --board <ADDR> --minutes 8 --out docs/results
```

The noise models run firmware-side only, so this pass streams from the board
while a local `ModelStepper` provides the paired reference for MARD. The stream
depends on the sensor noise RNG (no fixed seed — see `docs/FEATURE_IDEAS.md`
#25), so run it a few times and average if you need tight figures.

**MARD is in** (per the grill decision): it is the headline accuracy number a
CGM-sensor thesis is expected to report, and it is ~15 lines on the paired
reference/stream arrays.
